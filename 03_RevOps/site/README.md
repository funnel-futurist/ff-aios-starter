# Site

Your website or landing page lives here while it's small. Claude Code can scaffold it in this folder.

**Deploy with Vercel:** import this repository, then set **Root Directory** to `03_RevOps/site`. Vercel builds and deploys this folder only, so the rest of your workspace stays private. Step by step: `docs/human_steps/connect_vercel_to_a_repo.md`.

**When it outgrows this folder** (a production app, outside developers, its own secrets), it gets its own repository. Register it first, then move it.
