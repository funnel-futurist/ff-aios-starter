**What the upgrade does:**
- **Moves every file.** Every file the release doesn't manage under a 2.x folder moves, including files the person made. The longest matching rule wins, and each 2.x folder has a catch-all.
- **Refuses conflicts.** A file that would land on a different file already at the destination refuses the whole upgrade, with nothing changed.
- **Leaves nothing behind.** Anything left in a 2.x folder fails the upgrade, which then rolls back.
- **Reverses on every path.** Moves are journaled, so crash recovery and rollback both reverse them.
- **Refreshes untouched starter files.** A starter file the person never edited gets the 3.0 text, with the old text kept for rollback.
- **Never edits the person's words.** Edited files are only reported.
- **Names hosting changes.** A moved site is named, with the Vercel Root Directory to change.
