# Human steps

One card for each thing a person has to do by hand. When Claude needs you to act, it points you to the card instead of giving a bare command. If a card is wrong, that's a defect: say where it went wrong, and it gets fixed.

| Card | For |
|---|---|
| [run_a_terminal_command_from_claude.md](run_a_terminal_command_from_claude.md) | Running a command Claude gives you |
| [turn_on_github_2fa.md](turn_on_github_2fa.md) | Two-factor sign-in on GitHub |
| [remove_an_org_member.md](remove_an_org_member.md) | Taking someone out of your GitHub organization |
| [create_a_supabase_token.md](create_a_supabase_token.md) | A scoped Supabase access token |
| [download_a_supabase_backup.md](download_a_supabase_backup.md) | A backup of a Supabase database on your computer |
| [connect_vercel_to_a_repo.md](connect_vercel_to_a_repo.md) | Deploying a site from GitHub with Vercel |

Every card has: the exact address, numbered clicks, what success looks like, what to send back (never a secret), the official page it was checked against, and a video whose transcript was checked against the steps, or "still to find" if none matched yet.
